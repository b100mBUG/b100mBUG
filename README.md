- **MoneyManager**: Personal finance tracker built with KivyMD and FastAPI.
- **Hospital Management System**: Works online and over LAN, so it keeps functioning when internet access is unreliable.
- **CS Course Book App (Form 1 to 4)**: Non-profit learning app for Kenyan high school students. Structured content, quizzes, images, and video.
- **Social News App**: Share and discuss trending content, built around simple, fast interactions.
- **Admin Dashboards**: Content control, analytics, and user tracking for the systems above.
